# Movie Recommendation System 🎬

A content based movie recommendation system that suggests 
similar movies using TF-IDF and Cosine Similarity.

## 🌐 Live Demo
👉 [Try the app here!](https://movie-recommendation-system-5bmkgvutu3xh6zsy9gmy9f.streamlit.app/)

## 🎯 How it works
1. Enter any movie name
2. TF-IDF vectorizes movie tags (genre, cast, keywords)
3. Cosine Similarity finds most similar movies
4. Returns top recommendations with posters and ratings

## 🛠️ Tech Stack
- Python, Pandas, NumPy
- Scikit-learn (TF-IDF, Cosine Similarity)
- Streamlit
- TMDB API (movie posters)

## 📊 Dataset
TMDB 5000 Movies Dataset
- 4809 movies
- Features: genres, keywords, cast, director, overview

## 🔍 Example Recommendations
- Avatar → Aliens, Star Trek, Ender's Game
- The Dark Knight → Batman Begins, Batman Returns
- Avengers → Iron Man, Captain America, Thor
